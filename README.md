# Smart Surveillance System for Missing Persons & Criminal Detection  
### Real-Time Face & Weapon Detection with Alerting System

## 📌 Project Overview
The Smart Surveillance System is an AI-powered solution designed to identify missing persons and detect criminal activities in real time using computer vision and deep learning.  
It processes live video streams to detect faces and weapons and triggers alerts when a match or threat is found.

---

## 🚀 Features
- Real-time face detection and recognition
- Weapon detection using YOLO
- Live video stream processing
- Flask-based web application
- Real-time alerting mechanism
- Database integration for records

---

## 🛠️ Tech Stack
- **Language:** Python  
- **Framework:** Flask  
- **Computer Vision:** OpenCV  
- **Deep Learning:** YOLO  
- **Database:** MySQL  
- **Tools:** Git, GitHub, Jupyter Notebook
